# Security Policy

## Scope

EcoQuant Financial Intelligence is a research prototype. It is not a production financial service.

Do not use real credentials, funds, customer data, or private documents with this repository. Use only simulated, synthetic, or explicitly approved public data.

## Reporting a Vulnerability

Please report vulnerabilities through a private GitHub Security Advisory for this repository or through a private GitHub contact to the repository maintainers. Do not include secrets or sensitive data in public issues.

## Financial Boundaries

Any workflows, accounts, balances, or transactions represented here are simulated rails for research and demonstration. They do not connect to, represent, or operate financial institutions.
